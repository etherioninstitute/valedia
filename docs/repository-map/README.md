# Maintained repository map

Run `python3 tools/repo_map.py ensure` before using the map and after edits. `check` exits 0 only when the input content digests and all published artifact digests match. A missing/corrupt/stale map exits 1; configuration/runtime errors exit 2. `refresh` rebuilds even when current. All commands run locally without importing repository modules, contacting backends, or uploading code.

```sh
python3 tools/repo_map.py ensure
python3 tools/repo_map.py check
# Optional foreground polling; Ctrl-C stops it. No daemon is installed.
python3 tools/repo_map.py watch --interval 5
# Optional local full-source pack; never the default context artifact.
python3 tools/repo_map.py pack
```

The default uses a pinned real Repomix CLI with `output.files=false` to produce a small file tree, while `modules.json` contains static symbols, exact source lines and import targets. `navigation.md` has a compact complete module table and MiroFish entry points. No full-source pack is generated by ensure. Resolve `.repo-map/current.json` once and retain its generation directory when reading several artifacts. Use `docs/repository-map/ARCHITECTURE.md` for curated role descriptions and audit limits.

Example query, run from the repository (no repository imports):

```sh
python3 - <<'PY'
import json
from pathlib import Path
base = Path('.repo-map')
gen = base/'generations'/json.loads((base/'current.json').read_text())['generation']
index = json.loads((gen/'modules.json').read_text())
for module in index['modules']:
    if 'mirofish' in module['module']:
        print(module['path'], module['symbols'], module['imports'])
PY
```

Freshness covers recursive allowlisted Python code, documentation, map tools/tests, configuration, architecture instructions, Node/Python versions, runtime lockfile and installed Repomix package bytes. It detects content changes even if mtimes are restored, additions, deletions, renames and corrupt artifacts. It does not monitor excluded data, arbitrary external services or third-party dependency file tampering outside the Repomix package. Python standard-library classification depends on the Python version running the tool. Ensure detects input changes while building and retries at most three times; continually changing inputs fail clearly. After a build returns, further source writes can always make it stale: run check immediately before consuming it.

Publication uses a foreground process lock (`fcntl`, Mac/Linux), immutable generation directories and a single atomically replaced pointer whose manifest digest covers every artifact digest. Old generations remain available for readers and are never silently pruned. No background process, CI, git hook, Git initialization or MCP server is installed. This is a recovered tree without `.git`; release workflow is to run ensure then check and record the printed generation. Concurrent builders serialize; pointer readers validate complete generations. Incomplete/orphan generations cannot be selected by a valid pointer. This protects against process interruption and concurrent writers, not hostile processes with write access or loss of all storage power.

Input policy: only regular `src/**/*.py`, `docs/**/*.{md,txt,json}`, `tools/**/*.{py,sh,json,md}` and root `AGENTS.md` plus the two map config files. Excluded directories include state, keys, secrets, credentials, model(s), histories, outputs, cache, virtualenvs and `.git`; secret-looking names and all symlinks/sockets/special files are skipped. No state or ledger content is opened. Ledger Python source names are code, not ledger data. Source limits are 4 MiB per file / 64 MiB total. Repomix runs on a private staged byte snapshot, with an explicit newly written JSON config, an isolated temporary XDG config directory, no instruction files and no git log/diff loading. The installed explicit `--config` loader returns before local/global config discovery; no HOME or global settings are changed. Executable user/repo config is not loaded. Config changes require review alongside `standard_config()`; arbitrary options are rejected. Repomix secret checks stay enabled for default navigation and explicit source pack. Scanning is best-effort and may miss secrets embedded in otherwise allowed source; it is not a guarantee that a source pack is safe to share. Protected paths and symlink exclusion are separate hard boundaries. If Repomix omits a sensitive source file, the AST map still lists names/lines/imports without copying constants, docstrings or source text. Dynamic import/eval hints omit arguments.

Static import categories: `internal` resolves an indexed module; `internal_namespace` resolves a package namespace; `stdlib` is recognized by the current Python; `unresolved_relative` cannot resolve a relative target; `external_or_unresolved` could be third-party or missing local code. `from` imports retain the base plus definite child modules (imported names may instead be symbols). Entire ASTs are scanned, including conditional/lazy imports; dynamic import/eval/exec hints are conservative and incomplete. Syntax failures are recorded per module without executing code; a current map may therefore document invalid source. Freshness is distinct from source correctness.

## Portable local runtime

Requires Python >=3.10 and Node >=22. This delivery installed and tested Node 24.12.0 and Repomix 1.18.1 on macOS. Linux is supported by the relative paths and standard-library implementation, but was not execution-tested here. Runtime location defaults to `../runtime/repomix-1.18.1`, staging to `../tmp/repomix`; set `REPOMIX_RUNTIME`, `REPO_MAP_TMPDIR`, `REPO_MAP_NODE` or use `--runtime`/`--tmpdir` when relocating. In this installation all locations are on NIMROD_SSD.

Portable pinned metadata lives in `tools/repomix-runtime/`. To reinstall on another machine, choose a location on its intended data volume (commands run from repository root):

```sh
runtime="$(cd .. && pwd)/runtime/repomix-1.18.1"
cache="$(cd .. && pwd)/cache/npm"
staging="$(cd .. && pwd)/tmp/repomix"
mkdir -p "$runtime" "$cache" "$staging"
cp tools/repomix-runtime/package.json tools/repomix-runtime/package-lock.json "$runtime/"
TMPDIR="$staging" npm ci --prefix "$runtime" --cache "$cache" --ignore-scripts --no-audit --no-fund
python3 tools/repo_map.py ensure --runtime "$runtime" --tmpdir "$staging"
```

No network is needed for map refresh after installation. Initial npm installation/reinstallation may use the registry. The runtime pin is 1.18.1 with npm integrity `sha512-XtV1qD6akJSigQ3fBRex5v+rWcGa4i9cm2FL/M/PEtzO3u1uDiso3CtNbhlZiMIqJstAdy8mj2m1ynOzNnNB3g==`; the lockfile records dependency versions/integrities. Lifecycle scripts are disabled. No global install or config change is required.

Run meaningful fixture and actual CLI checks with `python3 tools/test_repo_map.py`; fixtures/staging are created under the configured SSD temp directory and removed. Tests create their own repository; no trading source is executed or changed.
